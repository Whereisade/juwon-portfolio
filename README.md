# Oluwajuwon Adewuyi — Architectural Practice & Portfolio

A professional, responsive portfolio website built with **Next.js**, **React**, **Tailwind CSS**, and **Lucide Icons** showcasing architectural drafting, 3D visualization, interior design, and project management services.

---

## 🚀 Features

* **Interactive Project Filtering:** Seamlessly filter projects across categories including *Residential*, *Commercial & Institutional*, *Renovation*, *Facade & Modelling*, and *Concepts*.
* **Dynamic Project Modals:** Clickable project details with full accessibility features (focus trapping, ESC key listener, body scroll lock, and ARIA attributes).
* **Responsive Layout:** Clean, editorial design aesthetic optimized for desktop, tablet, and mobile viewing with an integrated hamburger menu.
* **Service Capabilities Breakdown:** Clear display of remote architectural Revit and CAD drafting services.
* **Enquiry Contact Section:** Integrated form layout ready for backend email/form endpoint integration.

---

## 🛠️ Tech Stack

* **Framework:** Next.js (App Router / Client-side interactive components)
* **Styling:** Tailwind CSS
* **Icons:** Lucide React
* **Language:** TypeScript / JavaScript

## 💻 Getting Started

1. Ensure you have **Node.js** installed on your system.
2. Install dependencies:
```bash
npm install

```


3. Run the development server:
```bash
npm run dev

```


4. Open [http://localhost:3000](http://localhost:3000) in your browser to view the portfolio.
